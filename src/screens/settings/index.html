Settings

App

Start with Windows
Start the app in the background when Windows loads.

Metadata screen

Ignore captions in metadata
Ignores captions when generating metadata or checking for items without it.
Ignore labels in metadata
Ignores labels when generating metadata or checking for items without it.
Ignore text in metadata
Ignores text when generating metadata or checking for items without it.
Ignore embeddings in metadata
Ignores embeddings when generating metadata or checking for items without it.

Sync screen

Ignore deleted phone images
Ignore deleted phone images when syncing albums. If not ignored, deleted images in your phone will be deleted in your computer too.

Links

A link is formed by an album folder and a metadata file.
  • Add an album folder to enable backing it up.
  • Add a metadata file to enable generating metadata for its album.

Make sure you add links in the same order as in the phone app. No links
