Ignore deleted phone images when syncing albums. If not ignored, deleting an image in your phone will delete in your PC too.

Links

A link is formed by an album folder and a metadata file.
  • Add an album folder to enable backing it up.
  • Add a metadata file to enable generating metadata for its album.

Make sure you add links in the same order as in the phone app. No links
